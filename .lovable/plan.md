# Custom portfolio favicon

## Changes
- Create a lightweight square SVG favicon featuring an elegant serif “K” on a warm cream background with dark brown ink.
- Update the site-wide favicon declaration to use the new asset in browser tabs and deployed builds.
- Remove the old Lovable favicon file so browsers and crawlers cannot fall back to it.

## Validation
- Confirm the favicon asset is served from the normal public path.
- Verify the page head points only to the custom favicon and the project still builds successfully.
